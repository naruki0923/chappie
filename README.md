# チャッピー — 常駐アシスタント（初期実装）

macOS 14以降向け。小さな猫を画面の隅に表示します。Orreryを参考に、独立したネイティブアプリとして実装しています。

## 使い方

- ロボットをクリックすると会話パネルが開きます。音声呼びかけではパネルを開きません。
- ロボットをドラッグすると表示位置を移動できます。
- 「音声をオン」でマイクと音声認識を許可してください。
- 「チャッピー、今日の予定」のように続けて話すか、「チャッピー」と呼んで反応音の後に質問します。質問の後、約1.6秒の無音で送信します。
- 呼びかけ認識はMac内で処理します。一般の質問や旅行・外出の提案は、ログイン済みのClaude Code CLI（無い場合はCodex CLI）に送信されます。APIキーは使いません。
- ファイル名検索とMacのカレンダーの確認・追加はローカル処理で、結果をAIに送信しません。
- 「明日15時に会議を入れて」「来週の火曜10時に歯医者を追加して」で予定を追加できます。日時はMac内で解釈します。
- 「今日は何のゴミの日？」「明日のゴミは？」「今週のゴミ」で松山市 清水地区のごみカレンダー（2026年度）から答えます。「ペットボトルはいつ？」「蛍光灯は何ゴミ？」で種類ごとの直近の収集日と出し方。「粗大ごみ」は申込制の案内、「年末年始のゴミ」は12/28〜1/8の予定。Mac内のデータだけで答えます。
- 「30分後に電話って教えて」「金曜に振込をリマインドして」「9月23日に段ボール捨てるってリマインダー入れといて」でリマインド。時間を言わなければ聞き返します。時間になるとチャッピーが声をかけ、Appleリマインダーにも入るのでiPhone・Apple Watchにも届きます。「リマインドの一覧」で確認。
- 予定・リマインドはAppleカレンダー／Appleリマインダーのみ。claude.aiのコネクターは一般質問には見せていません。例外はメールの依頼だけで、そのときGmailの読み取りと下書き作成だけを許可します（送信・削除・転送・ラベル変更は不許可）。
- 旅行・会食の予約は「その案で予約して」「20日の東京から新大阪の新幹線を取って」で、条件入りの予約サイトを専用ブラウザに開きます。足りない情報（日付・人数）は聞き返します。支払い・確定は押しません。
- 「何が買える？」で登録商品の一覧、「シャンプー買って」で金額確認→「いいよ」で注文します。
- 商品の登録は会話でできます：商品URLを貼って「このURLをシャンプーとして登録して」（「2個」「上限3000円まで」も同時に指定可）。「シャンプーは2個にして」で変更、「ウイスキーは登録から外して」で削除。
- 設定から音声の返事・ログイン時起動・商品ルール・note参照URLを変更できます。
- メニューバーの猫から表示・終了できます。スリープ中や電源OFF中には反応しません。

## 現在実装している機能

| 機能 | 状態 |
| --- | --- |
| 小型の猫・常に手前・全デスクトップ表示 | 実装済み |
| ログイン時起動 | macOSのログイン項目として登録可能 |
| 呼びかけ・質問の文字起こし・音声で返事 | 実装済み。実機のマイク/音声認識許可が必要 |
| 「ファイル 請求書」などファイル名検索 | Spotlightで最大30件。Finder表示可能 |
| 今日・明日・明後日・今週・来週・今月の予定 | Macのカレンダー。旅行・出張の予定があればプラン提案を案内。OSのカレンダー許可が必要 |
| 予定の追加 | 「明日15時に会議を入れて」など。日時の解釈はMac内 |
| 予定の変更・削除 | 「明日の会議を16時にずらして」「会議を30分後ろに」「定例を金曜に移して」「今日の打ち合わせをキャンセルして」。候補が複数なら一覧を返して聞き直す |
| 予約の段取り | 「20日の東京→新大阪の新幹線を取って」「その案で予約して」「渋谷で金曜19時に4人の店」。直前の会話も踏まえて条件を整理し、Yahoo!乗換案内・Googleフライト・Booking.com・食べログの検索結果を条件入りで予約ブラウザに開く。選択・支払い・確定は本人 |
| 注文状況・到着予定 | 「今日買ったものはいつ届く？」「注文状況」「昨日頼んだやつ届いた？」。チャッピー自身の購入記録（ローカル）と、ログイン済み専用ブラウザのAmazon注文履歴（直近30日）を読んで答える。読むだけで何も押さない |
| Gmail | 「未読メールを要約して」で要点と要対応を報告、「田中さんに10分遅れると下書きして」でGmailの下書きを作成。送信・削除・転送はできない（claude.aiのGmailコネクター経由） |
| 空き時間 | 「来週で1時間空いてるところ」「明日の空き時間」。9〜18時で探す |
| ごみの収集日 | 「今日は何のゴミの日？」「来週の火曜のゴミ」「ペットボトルはいつ？」「乾電池は何ゴミ？」。松山市 清水地区の2026年度ごみカレンダー（2026/4〜2027/3）を `GarbageCalendar.swift` に書き写して参照。10/7・年始の休止、締切時刻を過ぎた後の案内、粗大ごみの申込期間（区分C/D）、「不燃ごみ」区分が無いことの説明も。範囲外の日はその旨を答える |
| リマインド | 「30分後に〜って教えて」「金曜に〜をリマインドして」。Mac上は声で通知、Appleリマインダー経由でiPhone・Watchにも |
| 旅行・出張・会食のプラン提案 | 行き先案を2〜3件、移動・費用・注意点つきで提案（Claude Code CLI経由） |
| 一般の質問・価格リサーチ | Claude Code CLI優先（Codex CLIは予備）。直近の会話を添えて回答。Web検索と出典を要求 |
| 購入ルール保存 | 商品URL・数量・送料込み上限・24時間の重複防止・通常購入のみ。会話・設定画面・CSVのいずれでも登録、会話と設定画面で削除 |
| Amazonの注文確定 | 登録商品の数量・上限金額を読み上げ、「いいよ」の後にチャッピー専用ブラウザで条件を再確認して実行 |
| TikTok Shopの注文確定 | **未接続** |
| noteを参照したリサーチ | 設定したURLをAIへ渡す。有料記事等、読めない本文は別途提供が必要 |
| 売上の取得（店側） | **未接続**。管理サービスの指定が必要 |

Amazon購入は、商品・数量・送料込み上限を登録した後、「商品名を買って」→金額確認→「いいよ」の順で実行します。商品・数量・送料込み合計・定期購入の有無をブラウザ上で再確認し、条件内だけ注文します。ログイン、OTP、CAPTCHA、住所や支払い方法の追加が必要な場合は止まります。

購入時はチャッピー専用のAmazonブラウザを使います。「Amazonにログイン」から一度ログインすると、WebKitの永続データ領域にAmazonのCookieが保存されます。チャッピーは認証情報を読み取りません。ログアウトやCookie削除は行いませんが、Amazon側の期限切れやセキュリティ確認で再ログインが必要になる場合があります。

## ビルドと検証

```sh
./test.command
./build.command
```

振り分けの確認は、UIを開かずに1問だけ答えて終了する `--ask` で行えます。

```sh
./dist/Chappie.app/Contents/MacOS/Chappie --ask "今日の予定"
```

`dist/Chappie.app` が生成されます。署名はアドホックです。再ビルドでOSの許可を再設定する場合があります。

Codex CLIは `/opt/homebrew/bin/codex`、`/usr/local/bin/codex`、Codexアプリ同梱の順で探します。`codex login` 済みの環境が必要です。会話処理はユーザーのCodex設定を読み込まず、read-only sandbox・シェルツール無効・アプリ連携無効・一時セッションで実行します。

参考：[Codex non-interactive mode](https://learn.chatgpt.com/docs/non-interactive-mode)

## 次に必要な情報

1. 予想の参照元note URL
2. 購入対象の名称・URL・数量・送料込み上限、希望する商品バリエーション
3. 予定のサービスと売上管理サービス
4. 購入先のログイン・配送先・既存支払い方法（認証や支払い情報はチャットに記入せず購入先で設定）
