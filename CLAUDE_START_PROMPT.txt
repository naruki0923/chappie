このリポジトリのデスクトップアシスタント「チャッピー」の開発を引き継いでください。

ユーザーはAPIを使いたくありません。Anthropic APIやOpenAI APIのキーを要求・保存せず、ログイン済みのClaude Code CLIを使ってください。

最初に outputs/chappie/CLAUDE_HANDOFF.md、outputs/chappie/README.md、outputs/chappie/Sources/Chappie 以下を読んでください。現在動いている機能を壊さず、未完了項目を優先順に進めてください。ユーザーはMac上で、小型ロボットをクリックして開き、「チャッピー」と呼びかけて命令する使い方を望んでいます。会話は日本語です。

重要な仕様:
- Amazon購入は登録済み商品だけを対象にする。
- 商品名、ASIN、数量、通常購入、送料込み合計を確認して金額を読み上げ、「いいよ」の明示回答後だけ注文確定する。
- 「やめて」でキャンセルする。同じ商品の連続購入防止と上限金額を維持する。
- AmazonのログインCookieはChappie専用WKWebViewに保存し、認証情報そのものは保存・出力しない。
- 購入の実地テストは、ユーザーが具体的に許可した場合だけ注文確定まで行う。
- 既存のロボットUI、クリックで展開、ドラッグ移動、常駐、Appleカレンダー、音声ウェイクを維持する。

まず `cd outputs/chappie && ./test.command && ./build.command` を実行し、現状を確認してください。その後、CLAUDE_HANDOFF.mdの「次に進める項目」に沿って実装してください。変更後はテスト、ビルド、/Applications/Chappie.appへの再インストール、実アプリの動作確認まで行ってください。
